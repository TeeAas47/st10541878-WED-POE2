# Choppies Supermarket Website

## 1. Project Overview

This project is a proposed website for Choppies Supermarket. The purpose of the website is to provide customers with clear and useful information about Choppies, its products, services, store locations and contact information.

The website is designed to be simple, professional and easy to navigate. It has been developed using HTML, CSS and JavaScript.

The website includes the following main pages:

- Home
- About
- Products
- Enquiry
- Contact

## 2. Website Objectives

The main objectives of the website are:

- To provide information about Choppies Supermarket.
- To display information about products and services.
- To make store and contact information easy to find.
- To allow customers to submit enquiries.
- To provide a contact form for general messages.
- To create a responsive website that works on desktop, tablet and mobile devices.
- To provide a simple and user-friendly navigation structure.

## 3. Website Structure

The website contains the following pages:

### Home

File: `index.html`

The Home page provides an introduction to the Choppies website and provides navigation to the other sections.

### About

File: `pages/about.html`

The About page provides information about Choppies Supermarket and the organisation.

### Products

File: `pages/products.html`

The Products page displays examples of products available from Choppies, including groceries, fresh produce and household products.

### Enquiry

File: `pages/enquiry.html`

The Enquiry page contains a form that allows customers to submit questions or enquiries.

### Contact

File: `pages/contact.html`

The Contact page provides contact information and includes a contact form and interactive map.

## 4. Technologies Used

The following technologies were used to develop the website:

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub

### HTML5

HTML5 was used to create the structure and content of the webpages.

### CSS3

CSS3 was used to style the website, including colours, fonts, spacing, layout, buttons, forms, images and responsive design.

### JavaScript

JavaScript was used to provide interactive functionality and form validation.

### GitHub

GitHub is used to store and manage the project files and development versions of the website.

## 5. CSS Styling

An external CSS stylesheet was created in:

`css/style.css`

The stylesheet is linked to all the webpages in the project.

The CSS was used to style:

- Page backgrounds
- Text and headings
- Navigation menu
- Buttons
- Forms
- Product cards
- Images
- Contact information
- Map container
- Footer
- Spacing and layout
- Borders and rounded corners
- Box shadows

The website uses a consistent green colour scheme to create a connection with the Choppies brand.

## 6. Navigation

The website contains a navigation menu that allows users to move between the different webpages.

The navigation links include:

- Home
- About
- Products
- Enquiry
- Contact

Hover effects were added to the navigation links using CSS pseudo-classes.

For example, the `:hover` pseudo-class changes the appearance of navigation links when the user moves the mouse pointer over them.

## 7. Responsive Design

The website was designed to work on different screen sizes.

CSS media queries were used to adjust the website layout for:

- Desktop computers
- Tablets
- Mobile phones

The responsive design includes adjustments to:

- Page layout
- Navigation
- Text sizes
- Product cards
- Images
- Forms
- Spacing

The website uses flexible layouts and responsive images so that content can fit different screen sizes.

### Desktop

The website is displayed using the full available screen width, with content arranged in a clear layout.

### Tablet

The layout is adjusted for medium-sized screens. Content and navigation are resized where necessary to improve usability.

### Mobile

The layout is adjusted for smaller screens. Content is displayed in a more compact arrangement so that users can view and navigate the website using a mobile device.

## 8. Images

Images are used on the Products page to make the website more informative and visually appealing.

The project contains product images for:

- Groceries
- Fresh produce
- Household products

The images are stored inside the project's `image` folder.

The images are also styled using CSS so that they remain responsive on different screen sizes.

## 10. Forms

### Enquiry Form

The Enquiry page contains a form where users can submit an enquiry.

The form includes fields for information such as:

- Name
- Email address
- Enquiry details

Validation is used to ensure that required fields are completed.

### Contact Form

The Contact page contains a general contact form.

Users can provide their details and message when contacting the organisation.

Validation is also applied to the contact form.

## 11. Interactive Map

An interactive map is included on the Contact page.

The map helps users identify the location of Choppies stores and provides additional location information.
